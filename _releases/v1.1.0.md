## 🗂️ New Groups

### READMEs: `practices/readmes`

The new [READMEs](https://github.com/fabricahq/public-rules/tree/v1.1.0/practices/readmes) practice group has 5 rules for writing a README that tells a reader what the product does for them and gets them to a working result. Agents load them when they write, restructure, or review a README, including before a release that changes setup steps. They tell agents to:

- Open with what the product does for the reader, before install steps, notices, or tables.
- Give a quick start that runs as written, with commands, versions, and sample output that match the release.
- State what the product does not do.
- Keep the README an entry point, and move reference material to the full documentation.
- Match the README's presentation to whether the product is primary or secondary.

Import it if your agents write or review READMEs, in any language. If you select groups by name, add `practices/readmes` to your `groups`. If you use `--groups '*'` or `--groups 'practices/*'`, you receive it automatically. (#11)

The library now has 13 groups containing 124 rules.
