### Every rule now follows the Code Rules rubric

All rules have been updated to conform to the [Code Rules rubric](https://code-rules.fabricahq.com/reference/rule-authoring/).

### We added our testing philosophy

The Testing group now includes Fabrica's [testing philosophy](https://github.com/fabricahq/public-rules/blob/v1.0.0/assets/testing-philosophy.md) as an available reference for some groups.
